# EdSim51 Demo

Use this if you want a fast 8051 simulation without rebuilding the full Proteus circuit.

## How to Use

1. Open EdSim51.
2. Load or paste `edsim51_port_demo.asm`.
3. Assemble the code.
4. Run the program.
5. Observe Port 2 bits switching in sequence.

## What It Demonstrates

- P2.0 = Light
- P2.1 = Fan
- P2.2 = Gate
- P2.3 = Doorbell
- P2.4 = Alarm
- P2.5 = Security

This is not the complete Bluetooth simulation. It is a simplified port-output verification.
